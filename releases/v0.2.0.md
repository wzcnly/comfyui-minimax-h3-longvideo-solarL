# v0.2.0 — 分段计划、缓存恢复与Sigma分段二采

本版在现有普通／SelfLift节点上增加分段计划与阶段缓存，同时兼容原有工作流。

- 每段独立净帧数与提示词，统一提示词可继承。
- 一采、增强阶段缓存，清单、完整性校验、目录互斥与恢复；支持复用一采重做增强。
- 普通节点新增split_sigmas模式，使用全帧high/low两阶段及边界预测x0；不需要额外标准二采节点。
- 缓存目录原生选择与清空；修复按钮／连线引起的参数保存错位。
- 实验性局部替换、续写、双端补段和音频上下文处理。

安装：解压完整插件到ComfyUI/custom_nodes，更新时完整替换旧文件夹；重启ComfyUI，再Ctrl+F5刷新页面并重新载入工作流。模型权重与第三方工作流依赖不含在发布包里。

缓存恢复需可核对的上游工作流和本机模型文件；隐藏外部状态、任意帧边界、无限时长不在保证范围内。整片二采仍受显存／内存限制。

验证覆盖Python逻辑、假采样调用链、H3接口及前端模拟。Windows目录窗口已实测显示和路径返回。未宣称完成真实GPU画质、音色或无缝接续验收。

旧版保留在v0.1.0，不删除或移动旧标签。
