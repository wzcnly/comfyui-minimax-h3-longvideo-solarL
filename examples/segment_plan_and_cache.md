# 分段计划与阶段缓存（2026-11-11）

两个Sampler均支持：分段净帧数、统一或逐段提示词、分段一采落盘、整片增强、任务清单及恢复。旧工作流不连接segment_plan且cache_directory留空时保持原行为。

## 使用

导入2080ti_分段计划与缓存.json或2080ti_分段计划与缓存_SelfLift.json。沿用旧示例的模型和第三方节点，需要原有依赖。新增分段计划节点的segment_plan接Sampler同名端口。

计划示例：
```json
[
  {"frames":124,"prompt":"人物走进房间"},
  {"frames":102,"prompt":"人物走到窗边"},
  {"frames":77,"prompt":"人物转身"}
]
```
共303净输出帧，内部额外处理重叠。首个非末段需为17k+5且至少22帧，后续非末段需为17k净新增帧；首段不小于重叠。末段可任意正整数。当前不支持任意中间边界的latent拼接。

prompt留空继承default_prompt。使用计划提示词需接CLIP，每段应有非空文本；全部留空则沿用上游positive。计划覆盖Sampler的帧数和重叠设置。整片增强使用default_prompt，空时使用第一段提示词，不实现增强阶段逐段文本时间调度。

## 缓存与恢复

cache_directory留空关闭；填写每个任务独立的绝对目录，例如D:/comfy/task_cache/project01/shot01。目录互斥，不可并发执行。manifest.json记录任务计划、阶段签名及状态；Tensor文件原子落盘并校验SHA-256。

普通Sampler缓存各段完整一采与整片二采。SelfLift缓存低分辨率x0、边界音频状态与完整高分辨率后段；两种阶段隔离。中断后重新执行相同任务，按阶段核对恢复。报告cache_hit=1表示跳过采样；条件编码、升分辨率及解码仍可能执行。修改二采设置会复用匹配的一采，重新执行增强。修改某段计划会使该段及后续依赖段失效；旧缓存保留。

正常通过ComfyUI界面或任务API执行时，隐藏PROMPT提供上游工作流。系统核对上游节点源码、已注册模型目录下可解析的文件内容、插件源码、Python/PyTorch版本，以及条件Tensor、目标latent、Sigma、seed、CFG等。相同身份支持跨引擎重启恢复；大模型内容校验有明显磁盘读取开销。

程序直接调用run而未提供cache_prompt/cache_node_id时，仅会话内复用。第三方节点从网络、未注册目录或隐藏外部状态修改模型时，标准工作流不能完整描述其状态，应更换缓存目录；不保证识别任意自定义节点的外部状态。

缓存损坏、清单版本不兼容时明确报错，可换新目录重做；不自动删除旧文件。仅使用可信本机任务的缓存目录。进程退出后OS自动释放目录锁。

## 验证与限制

72项Python测试通过，覆盖普通分段计划和二采、SelfLift完整阶段、缓存恢复、文件变更失效、损坏、失败与互斥；真实H3接口及前端回归通过。所有采样链路测试使用假采样，不代表完成GPU画质和听感验收。

输出仍是整批IMAGE和整条latent；整片二采受完整时间轴内存和显存限制。未实现时间分块二采、流式视频输出或任意中间帧边界拼接。磁盘缓存不意味着无限时长。
